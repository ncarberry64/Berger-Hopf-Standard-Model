# Conditional 2023 Student research route

Reviewer source and citation: [BHSM repository](https://github.com/ncarberry64/Berger-Hopf-Standard-Model).
This is a research experiment with one BHSM exterior optical geometry, interpreted
as surface topography/envelopment and counted once. It does not change the app's
mass-acceptance gate. A returned conditional point is not an accepted known-BH
recovery, calibrated interval, darkness measurement or horizon/core measurement.
The bounded 2026-10-24 native and actual-cadence control runs both completed with
numerically unresolved starts. They are retained failures of the point-resolution
gate, not accepted recovery. No numerical continuation launches automatically.
The separately reviewed v3 numerical method uses a full angular chart centered
on each original seed and a fixed gradient trust polish for every seed. It keeps
the same physical kernel, noise model, all 16 seeds, domains and 0.02 full-score
criterion. The helper defaults to this numerical method; `--method original-v2`
retains the original experiment. Every authentic execution still needs a separate
exact reviewed receipt. The v3 method is not an adequacy or mass-coverage result.

The kernel keeps the genuine positive 2023 HST marginal errors and explicitly
assumes independent Gaussian angular errors. OGLE uses a fully normalized
chronological unit-variance Student nu6 innovation law with seasonal/seeing/
brightness scales and an inferred seeing mean term. These are declared working
assumptions. The error-null 2025 data are not assigned manufactured errors.
The 16 angle/sign starts, all failures, rank/score checks, exact active faces,
lower trials and endpoint likelihood heights remain; heights are not mode
probabilities. Analysis boxes and angle seams are not physical confidence limits.

Default verification uses only the standard library and never imports the
scientific providers, makes network requests, generates observations or fits:

```powershell
python products/blackhole_tracker/research/known2023_student_20261024/bind_campaign.py
```

Use `product/` instead of `products/blackhole_tracker/` in the manuscript workspace.
The helper resolves its own source location; the current directory is immaterial.
An explicit `--core-path` can select a relocated geometry source with the same
reviewed hash. Full source integrity is in `SOURCE_MANIFEST_v3.json`; original
experiment provenance and the portable-test path-only change are recorded there.
The v1 manifest and failed v1 numerical-control contract are retained as history;
they do not override the current manifest or turn a failed campaign into a pass.

Preparing the reviewed runtime requires Python 3.11.9, NumPy 1.26.4, SciPy 1.12.0
and Astropy 6.0.0. A new runtime needs an additive reviewed binding. Run the focused
controls explicitly; only the small wholly invented fixture is included:

```powershell
python -B -m unittest discover -s products/blackhole_tracker/research/known2023_student_20261024 -p "test_*.py" -v
python products/blackhole_tracker/research/known2023_student_20261024/bind_campaign.py --prepare --purpose WHOLLY_INVENTED --input products/blackhole_tracker/research/known2023_student_20261024/invented_fixture_v1/INVENTED_DATASET_v1.json --output NEW_BINDING_DIRECTORY
```

Preparation writes an unadmitted freeze and structured commands to a fresh
directory. It does not run them. `--verify-existing PATH/POINT_FREEZE.json` checks
all existing source/input/registry bytes without fitting. Source relocation needs
a fresh binding; absolute paths in an old freeze are never silently substituted.

For authentic observations, obtain and verify the separately supplied original
2023 source pack using [the existing reproduction workflow](../README_JOINT_REPRODUCTION.md).
Its `--verify-only` action imports the unchanged sources without running the old
G0/G1/G2 fits. Use the input/time-reproduction environment recorded by that
workflow, then keep the resulting prepared file unchanged. This route accepts
only prepared raw bytes SHA256
`d2409db410e113872781494ca4d73db57d2a44fd65146c4e7ec2f40828448428`.
The existing wrapper emits the identical JSON body with a final LF, hash
`aa22272bea32ff17cf9be409822e7af52adc9520dbedeb877d62856d93bb3f7b`.
For that exact file only, add `--normalize-known-transport` to explicit
`--prepare`. The helper inserts one CR before the existing final LF, verifies
the exact D2409 hash, retains the original and new bound copy in the fresh output
directory, and records both identities. It does not parse/re-serialize the input,
change a numeric value or time convention, modify the caller's file or accept
any other hash. Default preparation remains strict and refuses that mismatch.
Do not recalculate unspecified native clocks to force the hash. The prepared file
retains all original raw data, selection/row IDs, calibration and time assumptions.
No original observations, actual-cadence daughter or 2025 native arrays are
redistributed in this directory. Original author/data terms still apply.

Use `--prepare --purpose AUTHENTIC2023 --input PATH/JOINT_2023_NATIVE_INPUT_v1.json
--output NEW_DIRECTORY` to create a binding. Actual execution separately requires
an exact reviewed execution receipt, as enforced by `run_known2023_point_v2.py`.
For a generated daughter also supply its exact `--registry`; every parent byte,
replacement ID and namespace is checked. The generic nonBH generating class is
an engineering assumption, not a universal classification from its chosen mass.

Each reviewed point run is bounded to 1,800 seconds, with 16 starts, fixed solver
phases and a latched audit-journal budget. Existing outputs are never overwritten.
Keep every artifact including failed modes. Student adequacy needs its own
refitted reference; old Gaussian chi-square screens do not apply. A point plus
one control cannot establish interval coverage or observational calibration.
There is no automatic bootstrap, mass profile, model change or BH promotion.

See `POINT_AND_CADENCE_PROTOCOL_v1.txt` and its v2 addendum for exact assumptions,
domains, time/exposure weighting limitations, solver criteria and later sensitivity
requirements. The product license and original third-party notices apply.
