# Reproduce the BHSM claim dossier's ideal controls

These are sixteen deterministic invented mathematical controls. They check
annular bending contrasts and covariance propagation, finite-lens exterior
degeneracy, projected multipole nulls, static enclosing-sphere identities and
the stated conditional assumptions. They do not fit observations, assign a
black-hole probability or implement a new envelope force.

The four original implementation files have unchanged bytes. Their pins are
recorded in `ORIGINAL_IMPLEMENTATION_PINS_v1.json`. `historical_evidence/` retains
the original full-source freeze, scoped decision, both Python-runtime receipts,
complete event/outcome logs and independent saved review. Those historical
records deliberately retain their original paths and hashes. Moving a file
does not repeat that scientific source review.

From any working directory, use the matching formal BHSM checkout:

```text
python /path/to/BHSM/products/blackhole_tracker/research/bhsm_claim_20261024/replay_ideal_controls.py --output /absolute/path/to/fresh_algebra_replay
```

In the development workspace the product directory is named `product/`.
Python 3.11 or newer is sufficient; this replay uses the standard library.
No observations, network connection or installed Tracker package are needed.
Use `--prepare-only` to record byte checks, new local bindings and the exact
command before executing it. Otherwise the command verifies original
implementation bytes, freezes its local source paths and runs the same sixteen
controls into a new output directory. Existing outputs are refused. The new
receipt is a deterministic replay, not sixteen independent new experiments.

The original driver retains its `--root-execution-admitted` flag. The portable
wrapper supplies it with a hashed local decision for the explicitly invoked
algebra replay. This is an audit record, not an external permission requirement,
registration, peer review or certificate of physical acceptance. The new local
freeze binds local source dependencies and the accompanying dossier; it does not
claim to reverify every one of the original fifty-five physical source files.

Read `../../docs/BHSM_ENVELOPMENT_CLAIM_AND_FALSIFIERS_V1.md` for the seven claim
contracts, falsifiers, nuisance conditions and unavailable measurements.
The BHSM description interprets one Einstein/GHY optical exterior as
gravitational hypersurface topography, counted once. Its core, microscopic
boundary and horizon remain outside these controls.
