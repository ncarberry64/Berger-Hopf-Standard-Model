BHSM INTERPRETATION
One gravitational exterior
In BHSM, surface topography includes gravitational spacetime geometry. When observations and the admitted model support a gravitational origin, the inferred exterior is interpreted as BHSM spacetime-side surface topography. One Einstein/GHY optical response is counted once; no additional force, mass or non-GR residual is required.
A fitted or nonrejected light curve alone does not validate that origin, uniquely verify BHSM or identify a black hole. A distinct microscopic interface, dynamical boundary response, horizon or core requires additional maps and evidence.

Integrity checks stored bytes and structure; it does not authenticate scientific claims. Numerical replay also recomputes saved-state objectives and contrasts. It performs no optimization, produces no new confidence interval and does not validate coverage. Replay is bounded and may take up to a few minutes.
Browser ZIP export/replay is limited to 128 MiB. A larger audit remains in its durable workspace; use the CLI/file workflow below. A 256 MiB evidence budget does not guarantee a browser-sized compressed ZIP.
Large-audit CLI/file workflow
Replace WORKSPACE_PATH with the durable workspace shown above. These are manual commands; nothing is run automatically.
blackhole-tracker mc-photometry export "WORKSPACE_PATH" --output "audit.zip" --max-archive-bytes 536870912
blackhole-tracker mc-photometry replay "audit.zip" --mode numerical --wall-seconds 120 --output "verification.json"
This command allows an archive up to 512 MiB; the file API accepts an explicit cap up to 2 GiB, with bounded expansion, state counts and replay time. Preserve the workspace if an export or verification fails.
