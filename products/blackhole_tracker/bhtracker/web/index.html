02 / ANALYSIS

Set the lens model

Recommended first fit

Fits the mass, location and motion of the same BHSM-described optical configuration, with a smooth tidal environment. No extra scalar response is required.

Advanced model options

R1 adds a conditional response from an adopted scalar–tensor action. It requires explicit flux and boundary assumptions; it is not needed for the ordinary BHSM interpretation.

Conditional response family
R1 fits a supplied exterior response. A fitted state does not establish a horizon or select a physical black-hole amplitude.

The expanded model allows more conventional explanations for the same data. Source positions remain free at each row.
