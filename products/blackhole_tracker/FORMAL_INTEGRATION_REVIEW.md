## Findings and concrete corrections

1. The first formal CI passed product source checks and tests on Linux and
   Windows, then failed the wheel build because `--no-build-isolation` assumed
   an installed backend. The corrected command uses the package's declared
   isolated build requirements. The initial failure log is retained in the
   external integration receipts; it is not described as a passing run.
2. Snapshot verification now rejects an empty/incomplete list, duplicated or
   unsafe/noncanonical paths, a mutable source identifier and changed bytes.
   A manifest does not include its own hash or a future formal commit.
3. The complete source archive includes both BHSM `LICENSE.md` and
   `ACADEMIC_USE.md`, because the first refers to the second. It includes the
   three paper directories, product and formal verifier helpers.
4. ZIP verification checks exact membership, every byte count and SHA-256,
   equality with the source tree, and all upstream product entries against
   their inner formal manifest. Independent small intact/tamper controls
   exercise changed bytes, added/omitted members, duplicates and traversal.
5. Optional developer source synchronization recognizes the formal directory
   layout and fixes generated CRLF output explicitly. Its equations and six
   original provider inputs are unchanged. The paper CI regenerates the
   complete theory tree in an isolated extracted archive and requires exact
   equality with the reviewed provider bytes.
6. TeX replay writes to a separate temporary directory, preserving the
   committed reviewed PDF and its bound visual-QA records. The source ZIP
   carries that reviewed PDF; the CI artifact also supplies the fresh build.
7. Three inherited angular-source files contain blank lines at EOF: its
   archived build log, `angular_geometry.py` and original action provider.
   Their bytes remain intact; the paper-level Git attributes scope a blank-EOF
   whitespace exception to those three paths. No new source receives that
   exception. The claim, status, frozen-integrity, readiness and precision
   audits pass; patch hygiene passes with this documented preservation rule.
