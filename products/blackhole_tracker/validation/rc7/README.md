# RC7 evidence and its limits

The scientific publication hold remains. No accepted independent known-black-hole
recovery or new black-hole identification is established. The public candidate
program preserves Gaia18ajz's previously published alternatives.

`CURRENT_KERNEL_STUDY_SUMMARY_v1.json` retains every block, criterion, exact
binomial interval and calibration flag from the completed synthetic experiment.
`all_planned_fits.csv` accounts for all 4,736 fits on 4,608 datasets. The full
original report, independent saved-only audit and attempt ledger are losslessly
gzip-compressed here; `COPIED_EVIDENCE_MANIFEST_v1.json` records the compressed
hashes and original payload hashes. Decompressing a report does not rerun it.
All three photometric calibration failures remain, including overcoverage.

The optional complete synthetic input/outcome evidence is under
`research/validation_20261024/evidence_public_v2/`, as three parts no larger than
40 MiB. Its manifest binds the 119,420,524-byte assembled public archive:
`91f501317821e937d22d52fbea20130995911ed2f1562409b073fc900fa7710e`.
The formal Git source/reviewer package retains those parts. The routine SDIST
omits their large payload and includes the retrieval/join instructions,
manifests, source and compact evidence. No archive is fetched during installation.
The public variant excludes the original native observation files and prepared
native parents; their hashes and explicit acquisition kit are provided. The
separate complete local archive is not redistributed as public source.

The experiment uses the recorded Python 3.14.3 numerical environment and a
frozen source snapshot captured before subsequent HTML wording changes. The
same seeds are regenerated only to check reproducibility, not counted as new
independent trials. The independent audit reads saved data/results and makes
no model, generator, optimizer or profile calls. Its pass verifies accounting;
it does not reverse the scientific calibration failures.

The wheel/install receipts cover the exact RC7 wheel
`0178c23099522ce5d608a36bce96693f9f197ba9f176776f35d57293f12d6c54`.
Source Python 3.14 and fresh installed minimum-family Python 3.11 verification
each pass 338 tests plus 66 subtests. The installed receipt retains the complete
scope, dependency versions, deprecation warnings and module-origin proof.
Research-control replays are deterministic software checks, not additional
calibration samples.

The browser/native receipt concerns a fresh regular installation, actual import
of all 734 original OGLE3-ULENS-0585 rows, its default fit and browser replay
download. Installed CLI replay preserves every row identity, the unavailable
quantities and BHSM interpretation, with zero prediction difference. A changed
but still syntactically valid JSON member is refused by the manifest hash check.
The separate row-integrity addendum compares every original numeric row and
source identity with the unchanged raw file. This is workflow verification,
not a new observational mass result.

BHSM interprets one Einstein/GHY exterior as gravitational hypersurface
topography, counted once. These receipts infer neither a microscopic core or
boundary nor a horizon, and do not supply a validated black-hole classifier.
