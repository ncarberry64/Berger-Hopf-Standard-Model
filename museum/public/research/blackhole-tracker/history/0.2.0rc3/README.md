# Historical 0.2.0rc3 distribution record

`DISTRIBUTION.json` is an archive copy of the exact rc3 receipt. The
public historical receipt is `../../DISTRIBUTION_0.2.0rc3.json`, kept at
the Blackhole Tracker release root so every original relative download
path continues to resolve normally. The versioned rc3 ZIPs, wheel and PDF remain
byte-for-byte unchanged. Shared notices, the synthetic forward fixture
and frozen pilot receipt are also retained there. The large source ZIP is
kept once rather than duplicated in this history directory.

The immutable rc3 Museum source is formal commit
`a43680dd183439dae3e9dfad03cea3d8042c4123`; the subsequent metadata-only
retention correction is `74b2035ff793e79e3352c0a7efb0febe109b0e9f`.
The latter CI retained one Windows proper-motion regression failure;
these historical artifacts are not relabeled as a passing rc4 release.
