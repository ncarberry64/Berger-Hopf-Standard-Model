# BHSM v11.2 Fixed Encapsulation and Relational Relativity

Intrinsic enclosure data `(h_enc, A_enc, L_enc, T_enc)` are distinguished from external data `(X, n, K, g_ambient, A_attach, Delta_rel)`. For an embedding variation,

`delta h_enc = i_X^*(delta g) + 2 sym(nabla xi_parallel) + 2 K_I xi_perp^I`.

Thus fixed intrinsic geometry during ordinary motion means restriction to an isometric-embedding constraint surface; it is not automatic for arbitrary motion. The current action supplies neither a stability theorem nor a constraint term enforcing this restriction. Its full-coframe audit fixes the intrinsic metric character to zero, while embedding and attachment characters remain open.
