# BHSM v11.2 Relational Spacetime Displacement

The coordinate-local candidate `Delta s²=g_ambient(Delta X,Delta X)` is a scalar under simultaneous coordinate transformation; globally, a Synge world function or boundary-to-boundary geodesic functional needs a specified domain. The author’s outward-displacement interpretation is a hypothesis.

For stationary conserved radial flux, `4 pi r² J_r=Phi` gives `J_r=Phi/(4 pi r²)`. This is geometric dilution, not by itself a force law, and it does not apply to parallel-plate Casimir pressure. The existing `q_D` shift current is retained; a physical spacetime-displacement or attachment-current decomposition is not action-derived.
