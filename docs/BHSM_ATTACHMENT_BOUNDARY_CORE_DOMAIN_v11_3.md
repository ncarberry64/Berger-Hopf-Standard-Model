# BHSM v11.3 Attachment Boundary and Core Domain

The attachment term contains no derivatives. Its new presymplectic potential, normal-momentum shift, and boundary flux therefore vanish. The existing capwise GHY terms and `Lambda54` seam matcher remain the differentiable boundary completion.

On the constraint, `I_W=upsilon I_C`. For bounded `I_C` as `upsilon->0`, both dressed terms behave as `sqrt(upsilon) I_C`, the on-shell attachment density vanishes, and the attachment source and flux remain finite. Ordinary encapsulation remains on `upsilon>0`; entry into the endpoint requires a separate de-envelopment domain, which is not constructed here.
