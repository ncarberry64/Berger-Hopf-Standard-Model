# BHSM v16.18: exact event-multiplier projection

At fixed orbit, period, and multipliers, the KKT stationarity covector depends
affinely on the event multiplier.  Its least-squares projection is therefore
exactly

\[
y_\rho=-\frac{\langle D\Gamma,D(E/\epsilon_E)\rangle}
                  {\|D(E/\epsilon_E)\|^2}.
\]

This corrects the one-dimensional multiplier block exposed by the v16.17
range failure.  It does not change the orbit, the soft-event equation, or the
eta margin, and it is not a substitute event or a new normalization.
