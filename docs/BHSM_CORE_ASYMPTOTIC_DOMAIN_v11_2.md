# BHSM v11.2 Core Asymptotic Domain

The core is the asymptotic end `upsilon->0+`, equivalently
`q_D->+infinity`, at infinite regular Haar distance. It is not inserted as a
degenerate point of the inverse-metric action.

Finite-cutoff Dirichlet and reflecting Neumann ensembles demonstrate local
flux cancellation but do not select a core response. Deficiency indices,
self-adjoint extensions, finite-energy/finite-flux asymptotics, incoming and
outgoing data, reflection, and transit remain undefined.
