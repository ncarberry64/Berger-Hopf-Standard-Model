# BHSM v11.3 Attachment Character and Current

Neutrality of the two dressed incidence terms, together with the adopted primitive generator normalization `|w_C-w_W|=1`, fixes

`w(I_C)=-1/2`, `w(I_W)=+1/2`, `w(Lambda85)=0`, and `w(h_enc)=0`.

For `upsilon=exp(-q_D/lambda_D)`, the action-derived source is

`J_attach=-(1/(2 lambda_D))<Lambda85,upsilon^(-1/2)I_W+upsilon^(1/2)I_C>`.

The recovered matcher is algebraic, so its linear `A_D` term and quadratic `A_D^2` completion are both exactly zero. Exchange is carried by this scalar source and the diffeomorphism Ward identity `Q_C+Q_W+Q_D=0`; no independent displacement current is introduced.
