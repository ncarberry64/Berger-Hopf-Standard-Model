# BHSM v11.2 Haar-Scale Closure

The six routes—generator redundancy, primitive character lattice, canonical
kinetic normalization, gravitational matching, boundary/core normalization,
and global scale—were tested. Canonical normalization fixes the regular
`q_D` kinetic convention but not the coupled charges `w_a/lambda_D`. Every
other route requires the missing primitive character ledger or later action
data.

`lambda_D` is positive but not set to one and is not classified as physical
or conventional.
