# BHSM v11.2 Covariant Phase Space

The regular scalar subsector retains
`Theta_D^A=-sqrt(-G) d^A q_D delta q_D`, its antisymmetrized symplectic
current, and the conditional canonical pair `(q_D,Pi_D)`. The boundary normal
momentum is `sqrt(|h|) n.dq_D`.

The complete symplectic current cannot be computed without the missing local
current couplings. No core response functional or core symplectic form exists,
so global flux conservation and physical kinetic rank remain open.
