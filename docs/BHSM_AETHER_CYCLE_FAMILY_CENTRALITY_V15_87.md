# BHSM v15.87: one-cycle family-centrality theorem

The physical cycle functional is already common to the gauge and composite
sectors:

\[
\Gamma_{\rm cyc}=\Gamma_{\rm reset}
 +\int_0^{T_*}\Gamma_\partial[\Phi_*(t)]\,dt.
\]

Let \(P_a\), \(a=0,1,2\), be the three orthogonal triality projectors and
let \(C P_a C^{-1}=P_{a+1}\). The localized parent operator contains no
triality-changing intertwiner, hence

\[
 P_aD_5P_b=0\quad(a\ne b),
 \qquad
 \Gamma_{\rm cyc}[\Psi]=\sum_{a=0}^2
 \Gamma_{\rm cyc}^{(0)}[P_a\Psi].
\]

Every derivative of the regulated determinant is therefore family-block
diagonal. In particular,

\[
 P_aY_fP_b=0\quad(a\ne b).
\]

The return is also \(C_3\)-equivariant, so \(CY_fC^{-1}=Y_f\). If
\(Y_f=\operatorname{diag}(y_0,y_1,y_2)\), this equation gives
\(y_0=y_1=y_2\). Equivalently,

\[
 \operatorname{Diagonal}(3,\mathbb C)\cap\mathbb C[C_3]
 =\mathbb C I_3.
\]

Using the v15.86 cycle residue,

\[
 Y_f^{\rm cyc}=23.855948\,I_3\ne0,
 \qquad M_f^{\rm cyc}=Y_f^{\rm cyc}H_*=0.
\]

Thus family centrality is forced for the current localized action. A general
circulant matrix is allowed by abstract \(C_3\) symmetry alone, but it is not
generated because its off-diagonal terms require a triality-changing
intertwiner absent from the parent action. The absence of family hierarchy is
a prediction of this symmetric branch, not a missing Yukawa normalization.
