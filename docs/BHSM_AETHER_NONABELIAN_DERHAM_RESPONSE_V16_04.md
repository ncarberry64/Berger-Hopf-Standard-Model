# BHSM non-Abelian de Rham response v16.04

In a Cartesian frame, let

\[
 G=(L_x,L_y,L_z)^T,\qquad
 {\cal C}=\frac{2}{R}I+\sum_a S_aL_a.
\]

The exact identities

\[
 {\cal C}G=0,\qquad
 P_0=G^\dagger G,\qquad
 P_{\rm spatial}={\cal C}^2+GG^\dagger
\]

reconstruct the scalar and one-form Hodge Laplacians, including the exact
longitudinal spectrum.

For a Cartan background \(a(\tau)e^3\), differentiation supplies scalar and
spatial transition/contact matrices. The full one-form vertex also contains
the temporal--spatial block

\[
 (P_1')_{0z}=-2i\,\dot a,
\]

which is the \(-2\,{\rm ad}(F_{0z})\) gyromagnetic coupling. The regulated
background response is

\[
 D^2\Gamma_{\rm adj}
 =D^2\Gamma[P_1]-2D^2\Gamma[P_0],
\]

with the global scalar gauge zero mode removed. Thus electric and magnetic
adjoint responses for \(SU(2)\) and \(SU(3)\) are generated by the same full
de Rham block and scale only by the fixed \(C_A=2,3\).
