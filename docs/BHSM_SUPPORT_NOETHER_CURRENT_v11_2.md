# BHSM v11.2 Support Current

For `delta Phi=+w epsilon Phi` and `delta A_D=d epsilon`, covariance fixes
`D Phi=nabla Phi-w A_D Phi`. The plus-sign derivative would require
`delta Phi=-w epsilon Phi`; using both plus signs leaves
`2w d(epsilon)Phi` and is rejected.

The isolated support kinetic term has a global shift symmetry. Its gradient
coefficient is `j_shift^A=-lambda_D^2 A_D^A=lambda_D nabla^A q_D`. The formal
response convention `J=-delta S/delta A_D` gives the opposite sign. This
functional derivative is only a source shorthand because `A_D=d log
upsilon` is composite, not an independent parent field.

Local support multiplication is not an action-derived gauge redundancy. No
primitive matter, wall, boundary, or core support current is available.
