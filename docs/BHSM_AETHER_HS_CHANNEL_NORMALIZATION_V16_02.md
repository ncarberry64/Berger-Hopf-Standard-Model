# BHSM HS channel normalization v16.02

The Fourier--Galerkin angular heat tail converges at 24 proper-time nodes:

\[
 \delta K_B^Y=6.12540769,\qquad
 \delta K_E^Y=-0.03006315,\qquad
 Z_H^{24\ {\rm pairings}}=0.06270988.
\]

The hypercharge response has the sign that reduces the classical cone
mismatch, but supplies only about \(0.22\%\) of the required hypercharge
correction.

The HS normalization is a channel-space statement. With family centrality,
the allowed pairing multiplicities are

\[
 D=\operatorname{diag}(9,9,3,3)
\]

in the up, down, charged-lepton, and neutrino channel basis. If
\(H_f=c_fh\), then

\[
 Z(c)=Z_{\rm pair}\,c^\dagger Dc,\qquad
 Y_f(c)=\frac{c_f}{\sqrt{Z_{\rm pair}\,c^\dagger Dc}}.
\]

Therefore the earlier per-paired-mode value is a nonzero kernel-basis vertex,
not yet the physical one-Higgs Yukawa normalization. The physical direction
\(c\) must be the eigenvector selected by the complete four-channel HS
Hessian on the replacement saddle.

The symmetric global KKT system has dimension 314. If and only if its HS
Hessian acquires a nonpositive eigenvalue, continuation with four homogeneous
neutral HS amplitudes per node gives the 410-dimensional broken-branch
system.
