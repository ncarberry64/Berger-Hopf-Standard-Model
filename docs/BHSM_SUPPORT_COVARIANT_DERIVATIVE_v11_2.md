# BHSM v11.2 Support Covariant Derivative

On `0<upsilon<=1`, local multiplication `upsilon -> t upsilon` gives the
composite flat connection

```text
A_D = d log(upsilon) = -(1/lambda_D)dq_D,
A_D -> A_D + d log(t).
```

For `Phi_w -> t^w Phi_w`, the unique sign convention compatible with that
transformation is `D^(w)Phi=dPhi-w A_D Phi`. Tensor weights add, dual weights
reverse, and contractions include every inverse-metric weight. With the
parent Levi-Civita connection, `D G=-w_G A_D tensor G`; it is metric-compatible
only if `w_G=0`. Boundary pullback commutes when the embedding is equivariant.
Fiber integration commutes only for basic `A_D` and an assigned fiber-measure
character. At constant `upsilon=1`, `A_D=0` and the parent derivative returns.

The connection is derived; primitive field weights are not.
The parent action does not make local `t(x)` a gauge redundancy. The local
law is therefore a representation-frame covariance test for the exact
Maurer--Cartan form, not a newly postulated gauge symmetry.
