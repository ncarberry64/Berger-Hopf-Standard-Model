# BHSM v11.1 Support-Functor Equivalence and Primitive Ownership

The two provisional representatives are
`R_D^(A)` with wall/fiber-measure characters `(1,0)` and `R_D^(B)` with
`(2,1)`. The machine-readable artifact records every requested primitive
object and action sector. Unknown weights remain null rather than inferred.

## Equivalence tests

As fixed one-dimensional representations, weights one and two are not
isomorphic: a nonzero linear intertwiner would require
`eta upsilon = upsilon^2 eta` for every positive `upsilon`. A field-dependent
map `Phi_B=upsilon^(Delta w) Phi_A` is nevertheless pointwise invertible on the
regular domain. It is not automatically a physical equivalence because

`d(upsilon^r Phi)=upsilon^r[dPhi+r Phi d(log upsilon)]`.

The additional support-gradient current, connection, kinetic, and boundary
terms are not known to be removable. The map is also singular at the core
`upsilon=0`.

A Weyl candidate has the eight-dimensional transformations

`sqrt(-G_tilde)=e^(8 omega)sqrt(-G)`

and

`R_tilde=e^(-2 omega)[R-14 Box(omega)-42(grad omega)^2]`.

Thus the Einstein-Hilbert density generates nontrivial derivative terms.
Gauge, fermion, scalar, and GHY terms transform with different factors; the
current repository has no complete supported action/domain on which all
cancellations and the canonical map can be checked.

Redistributing character between measure and integrand preserves an algebraic
integrated weight, but it has not been shown to preserve local equations,
stress, support current, symplectic form, boundary variation, core asymptotics,
or dimensional reduction. It is therefore not registered as representation
gauge freedom.

## Canonical and core comparison

The physical symplectic forms, stress tensors, support currents, reduced
kinetic/Hessian pencils, deficiency indices, self-adjoint extensions, and core
transfer domains cannot be compared without the missing local supported action
and boundary/core canonical domain. The earliest formal difference is the
wall character in fixed `Rep(G_D)`; the earliest physical test that is
undecidable is the regular support-gradient sector. A global equivalence fails
at least as a naive field map because it is singular at the core.

## Primitive ownership

Supported coframe, line element, normal line, Hopf generator, wall embedding,
core attachment, and normalized support current were tested. None is selected
by the existing action. The coframe ansatz gives weights `r_e`, `2r_e`,
`-2r_e`, and `8r_e` for coframe, metric, inverse metric, and D8 measure, but
the support definition does not fix `r_e`; adopting it would add a continuous
character rather than derive one. It also does not fix `lambda_D`.
