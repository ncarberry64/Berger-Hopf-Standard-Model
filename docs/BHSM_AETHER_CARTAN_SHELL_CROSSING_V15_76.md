# BHSM v15.76 normalized Cartan shell crossing

With the symmetrized Dirac convention,

\[
 \frac{\delta\mathcal L_D}{\delta\omega_{MAB}}
 =\frac i4e\,\bar\Psi\Gamma^{MAB}\Psi.
\]

Combining this with the totally antisymmetric contorsion part of the Einstein
term and eliminating contorsion gives

\[
 -\frac1{32K_G^{(5)}W}
 (\bar\Psi\Gamma_{ABC}\Psi)^2.
\]

The four-dimensional axial magnitude is \(3/(16K_G^{(5)}W)\), and its LR
Fierz projection has fixed magnitude

\[
 \boxed{\frac{c_{EC}}{K_G^{(5)}W}},
 \qquad c_{EC}=\frac34.
\]

No four-fermion coefficient is added.

On the last controlled child slice, the shell is reconstructed in proper
normal distance and fitted as

\[
 L_\eta(s)=L_{\min}+c_e(s-s_e)^2+\cdots,
 \qquad c_e>0.
\]

Using

\[
 J=(r/r_\partial)^3,
 \qquad
 u_0=\mathcal N J^{-1/2}\sin f,
 \qquad
 \mathcal N^{-2}=\int C\sin^2f\,d\chi,
\]

the leading Cartan kernel is

\[
 G_{EC}(\epsilon)=\frac{A_{EC}}{\sqrt\epsilon}+O(1),
\]

\[
 A_{EC}=\frac{3\pi}{4K_G^{(5)}}
 \frac{J_e|u_0(s_e)|^4}{\Lambda_e\sqrt{c_e}}.
\]

The reconstructed values give \(A_{EC}\simeq2.31\times10^{-3}\). With the
same regulated LR susceptibility used by the gauge calculation, the frozen
shell estimate is

\[
 \epsilon_{*,u}simeq3.1\times10^{-10}.
\]

The small gauge contribution orders the channels as
\(u>d>e>\nu\), so the up channel crosses first, although the splittings are
very small at this leading universal-Cartan level. This is a controlled
frozen-shell estimate, not yet the backreacted condensate solution. The next
calculation solves the gap and child KKT equations together in this event
layer.
