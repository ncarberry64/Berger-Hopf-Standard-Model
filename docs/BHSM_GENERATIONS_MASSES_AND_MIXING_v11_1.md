# BHSM v11.1 Generations, Masses, and Mixing

The frozen base-plus-two-excitation ledgers remain unchanged:

- lepton: `(0,0), (5,2), (9,3)`
- up: `(0,0), (6,0), (10,1)`
- down: `(0,0), (6,3), (8,2)`

V11.1 does not redo generation selection. It asks whether the supported action
owns the transport to physical localized modes. Because the support functor,
core transfer, and stable sector cycles are absent, monodromies, masses, CKM,
and PMNS remain undefined. No proxy stress is promoted.
