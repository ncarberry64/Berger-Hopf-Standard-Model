# BHSM v15.42 — pure-trace York continuation

For the response-constrained child, test the conformal metric

\[
h_7=R^2e^{2u(\chi)}
\left(d\chi^2+\cos^2\chi\,d\Omega_{3,u}^2
+\sin^2\chi\,d\Omega_{3,v}^2\right)
\]

and pure-trace extrinsic curvature

\[
K_{ij}=Hh_{ij},\qquad H'=0.
\]

The formal Hamiltonian equation is

\[
{\kappa_1\over2}(R_7+42H^2)-{\kappa_0\over2}
-(1-4\sigma^2)F(X_\eta)-\rho_{\rm FR}=0,
\]

where

\[
\sigma=C_J[f]-\frac12,\qquad
C_J'={\sin^2f\cos^2f\over\int\sin^2f\cos^2f\,d\chi}.
\]

The KKT response replaces the independent inverse-Euler skin action, so
there is no separately counted \(\rho_\sigma\).

Solving \(u\), \(H^2\), the localized inertia, and the FR normalization
produces

\[
\boxed{H^2<0.}
\]

Therefore no real pure-trace CMC slice belongs to this branch. This fixes the
kinematic sign: the positive static Hamiltonian defect must be cancelled by
the negative \(K^2-K_{ij}K^{ij}\) contribution of trace-free join-shape
shear. The next construction solves that shear together with its eta momentum
companion, so the momentum constraint is satisfied pointwise.
