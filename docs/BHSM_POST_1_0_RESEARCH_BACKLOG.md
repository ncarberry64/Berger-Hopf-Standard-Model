# BHSM post-1.0 research backlog

These items are scientifically interesting but do not block the internal
BHSM 1.0 finish line unless a later dependency audit ties one to a retained
headline deliverable.

| Category | Nonblocking work | Why it is off the critical path |
| --- | --- | --- |
| exact branch restoration | restore the generic fixed-h neighboring branch | the reduced family is the operative local scalar object |
| isolated cancellation | higher orders at the unselected branch-cancellation value | no frozen mechanism selects that value |
| perturbation theory | arbitrary orders after the first physical interaction | no retained headline dependency |
| vacuum catalogue | every nonlinear solution and global vacuum classification | only prediction-used configurations must close |
| topology catalogue | every boundary topology and admissible manifold | outside the finite claim set |
| quantum gravity | full nonperturbative quantum-gravity completion | outside BHSM 1.0 claims |
| all-loop RG | every loop and threshold | only minimal retained scheme maps are required |
| collider catalogue | every amplitude, process, and full hadronization | collider production is not a current 1.0 claim |
| downstream matter | all hadron, nuclear, atomic, molecular, material, biological, or engineering structure | scope-creep firewall |
| astrophysics/cosmology | full simulations and complete cosmological history | no retained frozen prediction requires them |
| black-hole catalogue | classifications unrelated to a retained claim | no headline dependency |
| external HEP runtime | licensed FeynRules/MadGraph production for unclaimed outputs | becomes blocking only if added to the official deliverables |
| external acceptance | peer review, citation, endorsement, or future confirmation | external validation follows release |

Items move back to the critical path only through an explicit blocker-DAG
edge identifying the affected headline artifact.
