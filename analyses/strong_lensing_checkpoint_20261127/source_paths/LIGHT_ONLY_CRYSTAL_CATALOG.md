# Invisible-crystal catalog: light-only BHSM research route

Entries are optical response patterns and BHSM envelope candidates, not material crystals, foreground mass reconstructions, or identifications of a physical mechanism. No conventional or BHSM envelope equations enter this catalog. A repeatable pattern qualifies as a candidate benchmark; a BHSM attribution requires a specific, fixed BHSM expectation to beat a conventional optical explanation on observations not used to pick it. Keep a known-copy cross-band prediction separate from locating a genuinely new copy or predicting a time delay.

## Frozen transfer: WFI 2033−4723

[Webb program 1198 observation 4](https://www.stsci.edu/jwst/phase2-public/1198.pdf#page=4), calibrated NIRCam mosaics, same filters as HE 0435. Use F115W to initialize and locate each known image, and the other three quasar images to solve one common translation into each target filter. Aperture sizes, Gaussian/Moffat point profiles, linear/quadratic background, and the strict <5 mas threshold were carried across unchanged. Withhold the corresponding target-band image each time. The [published configuration](https://doi.org/10.1051/0004-6361/202554359) identifies the fields and image labels; no mass model or positions from that work determine the score.

All 12 image/filter cases have median error below 5 mas (1.09 to 4.31 mas), but the strict all-variants rule is a near pass, not a full pass: 139/144 sensitivity realizations below 5 mas (overlapping, not independent). Worst miss 5.63 mas at A1 in F356W; A1 in F277W and B in F277W/F356W also go above 5 mas in some reductions. The two lens fields therefore support a useful approximate 5 mas robustness scale for known compact-image registration, not a universal 5 mas prediction, absolute astrometric limit, new image prediction, or a detected BHSM effect. The shortest band gave cleanest WFI transfer in this run. Next discrimination use independently resolved host structure across regions not included in a mapping.

Replay: wfi2033_crystal_transfer.py / .json, with archive cutout fetch and input hashes in wfi_crystal_inputs.

Hamilton's Object pixel-patch control: on the A→B outer clump the mirror predicted substantial real light in the held aperture (median 44%/54% SSE gain across F110W/F160W over no clump), but a single circular transported clump was nearly as good (42%/52%). Catalog as coarse host-feature transfer only, not a fine morphology benchmark. See HAMILTON_LIGHT_ONLY_CHECK.md.

## External resolved transfer: Sunburst Arc, frozen variant failed

[Frozen protocol](CRYSTAL_RESOLVED_TRANSFER_V1.md) compared the constrained BHSM light-only map (uniform scale and orientation, parity learned from training alone) against standard affine, with the same six local training matches and candidate target knot withheld. Uses observed coordinates only from [Sharon et al. Table 2](https://astronavarre.github.io/files/Sharon_2022_ApJ_941_203.pdf#page=6), not the published mass model/magnifications. Seven qualifying copy pairs, 122 directional cross-validation predictions. Pooled image-plane RMS 0.997″ vs affine 0.455″, median 0.242″ vs 0.101″. Only pair 7–8 wins both directions: 0.613″ vs 0.839″ and 0.222″ vs 0.387″. Not a general advantage; the uniform-stretch version does not transfer reliably. Standard affine allows direction-dependent stretch; any training-only criterion for deciding when to constrain it must be tested on another lens, not tuned and declared validated here. Replay: sunburst_crystal_transfer.py/.json.

## Hybrid development rule v2: geometry constrained by light

Blend the parity-aware scaled similarity with the standard affine map. For each prediction select the continuous affine fraction between zero and one by leave-one-out predictions within only the six training landmarks. Refit endpoints on all six and predict outer withheld landmark with their weighted combination. No foreground masses or lens equations, no need for the withheld coordinate to choose the blend. Sunburst RMS 0.997″ uniform, 0.482″ hybrid, 0.455″ affine; Hamilton RMS 0.812″ uniform, 0.311″ hybrid, 0.298″ affine (all query knots, both directions, all pairs; not the prior outer-only score). The candidate largely recovers standard geometry but does not outperform it. Treat both datasets as development now. Build on affine as default and require prospective evidence for added optical structure on a new independently resolved system. Replay crystal_hybrid_v2.py/.json.

## Route agreement and landmark budget

For a local 2D prediction, the BHSM light-only triangle route takes a point's three barycentric weights in one image and applies those weights to the matching triangle in the other. On the exact same three non-collinear matches, the triangle and the standard affine solve are algebraically equivalent and agreed to below (4\times10^{-14}) arcsec in 164 numerical checks. This is not a BHSM-specific invariant or evidence for an envelope. The three-marker solve uses three target correspondences, choosing them by the biggest source-plane image triangle (in the reference image, not the unlensed source plane) within the six nearest eligible matched landmarks. It still assumes that the six candidates have counterparts; the study does not validate a blind search or automatic match selection.

Across 122 held-out predictions on Sunburst: spread 3 RMS 0.473″, nearest 3 RMS 1.523″, nearest 4/5/6 affine 0.423/0.580/0.455″. Across 42 predictions on Hamilton: spread 3 RMS 0.370″, nearest 3 RMS 2.710″, nearest 4/5/6 affine 1.053/0.363/0.298″. The three-point median worsens on both cases relative to six points. On just the 10 Hamilton interpolations inside the selected triangle, spread 3 RMS 0.134″ and affine 6 RMS 0.130″; this did not extend to Sunburst's 34 interpolations (0.337″ vs 0.232″). No universal data-budget advantage; also no monotone benefit from adding nearby but poorly distributed points. This is a comparison of two methods for the same local map, not of a mass-based whole-lens model's ability to predict other images or delays. See crystal_landmark_budget.py/.json.

## Enlarged landmark budget

Paired audit of the same 94 Sunburst predictions across the five image pairs with 8+ shared matches. Withhold the target knot and compare the six nearest matches against all 7–10 remaining matches, unchanged geometry and hybrid training rule. Hybrid RMS fell 0.539″→0.499″ and maximum fell 2.139″→1.793″, but median worsened 0.139″→0.178″. Affine shows the same tradeoff (RMS 0.511″→0.488″, median 0.106″→0.164″). Expanded hybrid fits improved pooled directional RMS in two of five pairs, worsened three; image pair 3–4 worsened 0.038″→0.080″ going from six to ten. Hamilton's seven matched features do not permit enlargement with one held out. More eligible landmarks are useful as a pool but not automatically as inputs to one equally weighted local fit; wider coverage can stabilize some predictions and hurt others. No independent statistical replication. Replay crystal_more_landmarks.py/.json.

## Adaptive local-versus-wide selection

Used the same 94 Sunburst queries with six vs all (7–10) training matches. Inside each outer holdout, hide each training knot in turn and predict it from the nearest five or all remaining training knots (decrement both candidate budgets by one during inner validation). Choose the outer budget with lower summed inner squared error, ties go local. Score against withheld target only after selecting. Verified modifying each held target leaves the selection and predicted coordinate unchanged. For hybrid, chose wide 38/94, pooled RMS 0.516″ (local 0.539″, wide 0.499″), median 0.150″ (0.139″, 0.178″), worst 2.081″ (2.139″, 1.793″). Affine adaptive RMS 0.5095″, local 0.5109″, wide 0.4884″; median 0.1482″, local 0.1058″, wide 0.1644″. Adaptive correctly stayed local for every knot in pair 3–4 but no general advantage over both fixed budgets. One known system, dependent tests, development diagnostic. Replay crystal_adaptive_landmarks.py/.json.

## Map-disagreement warning

For the same 94 Sunburst predictions, compute the true distance between six-nearest and all-match predicted positions and score their midpoint (never use a target coordinate in either map). Using an illustrative 0.25″ disagreement warning in the hybrid, median midpoint miss was 0.347″ flagged vs 0.100″ unflagged. It caught only 7 of 15 misses at least 0.5″. Worst unflagged miss was 1.798″ on knot 7, image 4→8, where maps agreed within 0.018″. Half-spread did not cover observed error in 76 of 94 nested cases. Keep spread only as a sensitivity flag; never treat it as an uncertainty interval or use map agreement as confidence. Exploratory on one system. Replay crystal_map_disagreement.py/.json.

Independent corroboration (background audit, affine rather than the hybrid): [Treu et al. Table 4 and Figure 3](https://ar5iv.labs.arxiv.org/html/1510.05750), 22 matched Refsdal host knots, 132 dependent held-out transfers. Nearest six/all 21 median 0.210/0.331″ and max 2.321/1.489″. For knot 1.8, 1.2→1.1, predictions differ 0.062″ but both miss >0.5″ despite interpolation inside both training hulls. On removing the two closest input-image knots as well, 1.20 (1.3→1.1) gives 0.068″ disagreement versus 0.901/0.854″ misses. Keep separate sensitivity and blocked-validation error columns.

## Working light-only prediction rule: local inside, exploratory outside

Use one local affine map (translation, rotation, directional stretch and optional reflection) from the six nearest matched light landmarks in the reference image. If the query is outside the polygon formed by those six landmarks, label it extrapolation; show a search region or collect landmarks around the query, not a precision point. If the six are effectively collinear, do not solve. Retain the all-landmark affine map as a shape/sensitivity comparison, not a second vote or error bar. Do not auto-average. This is a working operating rule for matched structures across known copies, not for finding a new lensed image or predicting delays.

Stress test: hide a query's target coordinate and also remove its two closest training landmarks by reference-image position only. Compare local six, all remaining, and their midpoint on the same targets; only pairs with at least nine shared knots qualify. Uses Sharon Table 2 and Treu Table 4, without mass models. Local inside-polygon median errors are 0.163″ (20/62 supported Sunburst transfers) and 0.241″ (50/132 supported Refsdal transfers), vs 0.235″ and 0.393″ outside. Supported local RMS is 0.315″/0.438″ versus 0.334″/0.517″ for wide and 0.324″/0.467″ for midpoint on the identical supported targets. Supported worst misses still reach 0.943″/1.128″. For unsupported locations, the local/wide ordering in RMS reverses across the two systems, so no general fallback precision claim. For the same paired targets with no neighbor removal, supported medians are 0.047″ and 0.141″ (support sets differ with removal). All evaluations are development checks with dependent predictions, not independent confidence limits. The rule should now stay fixed for a new resolved lens (record support coverage together with error, keep full patch out). Files crystal_blocked_rule.py/.json and refsdal_treu_table4.json. This does not confirm a physical BHSM envelope.

## New-arc transfer with the rule held fixed: Warhol Arc

Used all eight matched light knots from Perera et al., Table 4 (doi:10.1093/mnras/stag486; https://borowiecki.dev/pdf/2511.04748), observation coordinates only. This is a new arc/feature set within the previously used MACS J0416 cluster, not a separate cluster. Each of the two directions withholds one knot in the target image, uses six nearest matched reference knots in the local affine fit, and uses all seven as the comparator; source-image local hull labels extrapolation. Same local rule as above, no coefficients or thresholds retuned. Moving the withheld target in software leaves all predictions bit-identical. Eight knots permit one-feature holdout but not the stronger two-neighbor block at fixed six-point training size.

Four of 16 dependent transfers are supported. Their local median miss is 30.4 mas, maximum 34.7 mas, RMS 30.9 mas vs 34.0 mas for wide and 32.2 mas for midpoint on the same targets. Twelve flagged extrapolations have exploratory local median 47.1 mas and max 80.8 mas. Single pair, small and correlated sample, no pixel-level masking or independent uncertainty claims. The rule transfers as a position predictor at selected landmarks, with limited coverage; it does not establish an advantage over conventional mass modeling or a physical BHSM effect. Replay: crystal_frozen_warhol.py/.json, warhol_perera_table4.json.

## Different-cluster patch holdout: RCS0327 (figure-level)

The frozen local-six affine rule and reference-image support polygon were carried to images 3 and 4 of RCSGA 032727−132609 (Sharon et al., Fig. 1, https://arxiv.org/pdf/1202.0539#page=2). Measured published leader tips, not native centroids or delensed points. Arcseconds are approximate, tied to the same objects in the Fig. 2 plate, its 10″ scale bar, and the printed 1.5x magnification of the Fig. 1 counterimage panel. Used the left (unrepeated) labeled g on image 3; c lacks a separately readable pointer there. The authors themselves caution about c/d/f. Catalog 10 readable pairs, including uncertain d and f. Flag these independently of errors. The stronger block hides each target plus its two closest reference-image neighbors; local-six uses 6 of the 7 remaining pairs. Mutating all three hidden coordinates left predictions exactly unchanged. Independent replay is byte-identical.

* All-labeled, two-neighbor block: 20 dependent predictions, five inside the six-landmark support polygon. Supported local median ~0.21″, RMS ~0.30″, max ~0.53″ vs wide RMS ~0.29″ on the same five (midpoint ~0.30″). Unsupported local median ~0.35″, worst ~1.01″. Three of the five supported predictions score uncertain d/f, so the ~0.21″ headline is not a robust accuracy estimate. Under an illustrative fixed-seed figure-marking perturbation, supported median 10–90% sensitivity spans ~0.26–0.54″, not a confidence interval.
* Higher-quality-only check: eight matched landmarks, therefore only one-feature holdout possible without reducing the fit budget. Four of 16 predictions are supported, median ~0.33″, RMS ~0.36″ (wide ~0.36″); unsupported median ~0.19″. Bracketing did not reliably improve error here. It is an extrapolation label, not a precision certificate.

No general advantage versus wide and no evidence for a physical BHSM effect. Keep frozen operating rule, use the source as a provisional cross-cluster stress test, and require calibrated native-image positions before quoting an accuracy for paper use. No time delay or pixel-patch reconstruction tested. Replay crystal_frozen_rcs0327.py/.json and rcs0327_sharon_fig1.json.

## RCS0327 calibrated Hubble pixels: equal-target six versus seven

Hubble Legacy Archive GO-12267 WFC3/UVIS F390W, F606W, F814W calibrated drizzled cutouts, 0.03962″/pixel. Published Figure 1 labels seed local image measurements; Gaussian-plus-plane measurement on actual HST pixels replaces reading pointer positions as measurements. Native-image F606W at radius 7 is primary; radii 6 and 8 and both alternate filters are sensitivity replays. Figure flags d/f omitted; both snap near e in image 4, corroborating that they cannot supply distinct targets. c lacks a readable separate pointer in image 3. Eight usable labeled pairs provisionally allow one withheld landmark (six vs seven retained); they do not allow the earlier three-feature block without reducing the frozen budget.

On the three of 16 F606W directed holdouts inside the local footprint, RMS is 0.166″ for six versus 0.168″ for seven, median 0.175″ versus 0.171″, both max below 0.20″. The same three queries and coverage are used for comparison. Across all 16 numerical fits (including explicitly flagged extrapolations), RMS is 0.200″ versus 0.215″, max 0.404″ versus 0.399″. Local had slightly lower supported RMS in all nine variants, but support is only 2–4 of 16 per variant and the tests are correlated. A stricter sensitivity filter requiring all centroid shifts to stay within 0.10″ across filters and apertures retains only four matched knots, too few for the test. This filter conflates extraction instability with real wavelength-dependent morphology; it is diagnostic, not an independent astrometric confidence limit. Both fits already know the match identities and the candidate pool; the saving is one match in the solve, not one fewer correspondence to establish. The comparator is an all-match affine fit, not a full mass-based lens model. Feasibility on calibrated positions, not an established methodological or physical advance. No proof of general precision or a full held-patch test. Replayed byte-identically; both predictions invariant to perturbing withheld target coordinates. ## Whole three-knot patch holdouts on calibrated-image catalogs

Sharon et al. Table 2 (Sunburst) and Treu et al. Table 4 (Refsdal host) provide image-plane positions of resolved light knots. For each directed image pair with ≥10 common knots, group each input knot with its two nearest input neighbors, deduplicate identical triplets in that direction, and hide all three corresponding target coordinates together. One affine fit predicts all three, using the six nearest remaining matches to the reference patch centroid, versus one affine fit using all remaining matches. A patch is counted as supported only if all three reference knots are inside that fit's training hull. No target image mass model or pixel patch used. This tests patch landmark locations, not held-back surface-brightness reconstruction. Test geometry known previously in the individual-query benchmarks, so this is a stronger holdout design on development systems, not independent lens confirmation. All predictions survive held-target mutation exactly; replay byte-identical.

Sunburst: 35 directed patches; six supports 7, wide (7–8 matches) supports 9. On the same 7, local/wide RMS 0.458/0.464″; 5/7 both put all three within 0.5″. Refsdal host: 88 directed patches; six supports 20, wide (19 matches) supports 46. On the same 20, local/wide RMS 0.374/0.443″; 16/20 versus 12/20 put all three within 0.5″. Supported worst individual misses on both systems exceed 1″.

At each fit's own coverage, local gives all-three ≤0.5″ on 21 of 123 possible patches and wide on 33 of 123, counting unsupported cases as no precision output. Six matches competes on shared coverage but does not preserve coverage. Exploratory routing comparison (not frozen independently): take local where supported, otherwise wide where it supports all three, otherwise abstain. Covers the same 55 as wide and yields 37 full-patch ≤0.5″ successes versus 33 (tied Sunburst, +4 Refsdal). This replay does not validate the router prospectively and does not reduce the catalog needed to identify matches or evaluate support. Patch sets overlap and directions repeat the same astrophysical structure; do not use independent-trial errors. Files: crystal_full_patch.py/.json.
