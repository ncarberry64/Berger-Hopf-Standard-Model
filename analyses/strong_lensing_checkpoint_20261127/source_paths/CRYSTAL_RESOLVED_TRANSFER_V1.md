# Frozen light-only cross-lens positional test v1

Hamilton's development result suggests a scaled local mirror can generalize better than a fully flexible affine map. Before reading Sunburst coordinates for scoring: take all source families belonging to the Sunburst Arc itself with published observed sky coordinates. Include all ordered image-copy pairs sharing at least seven uniquely identified knots, with no selection on target residuals. For each query knot, train on its six nearest other corresponding knots in the reference image (Euclidean tangent-plane distance), withholding the target position of the query. Fit a similarity map with parity fixed by the ordinary affine map on those same six; negative parity is rotation+uniform scaling+mirror. The comparator is an unconstrained affine map, same six training correspondences. Equal weights, no loss tuning or target-band centering. Score two-dimensional image-plane residual in arcseconds. Report all pairs, count RMS wins by unordered pair requiring both directions for a win, and pooled RMS/median. Pass for this single external system requires pooled squared-error reduction >=10%, medians that also improve, and >50% of unordered pairs better in both directions; independent lenses would still be required for a general advancement claim. Same source and overlapping training sets do not yield independent statistical replications. This is geometry transfer, not a test of a new physical field. If the published knot IDs do not provide consistent copy correspondence, document it and use independent position tables or admit no result.
