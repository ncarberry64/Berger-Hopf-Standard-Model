# Frozen light-only patch router v1
Primary criterion: number of eligible directed three-feature patches with all errors ≤0.5 arcsec at the same coverage as wide alone. Also report paired RMS, worst miss, and coverage. Require ≥10 shared observed feature IDs in a pair. Input patch is seed + two nearest same-image features, deduplicated in each direction. Retain the same patch-building, affine fit, convex hull, coordinate-only metric and deterministic tie order as crystal_full_patch.py. Lock before scoring any fresh system.
If whole patch inside the six nearest remaining landmarks around patch centroid, choose local map. Else if whole patch inside all remaining landmarks, use wide. Else abstain. No test coordinate or matter model may influence routing. Same coverage as wide by nested hulls; savings refer to fit inputs, not catalog construction. A tie or loss is reported without retuning. Published matches are allowed; report whether they were model-assisted. This evaluates coordinate transfer, not time delay, pixel reconstruction, or physical BHSM.
