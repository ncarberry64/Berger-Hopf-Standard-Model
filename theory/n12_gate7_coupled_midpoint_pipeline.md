# Actual midpoint proof with tighter normalized endpoint fields

The original midpoint-domain calculation remains preserved. It uses valid
uniform endpoint fields, but their normalization loses a common-scale
correlation. Its first eigenpair proposal campaign did not establish a
contraction on the resulting outer domain.

This pipeline first requires independently paired endpoint refinements from
`n12_gate7_coupled_physical_normalization.md`. Those refinements use only the
same paired eigenpair/response systems and their proved identities. They do not
change any physical endpoint radius, action, step, frame or branch rule.

Apply the unchanged actual-HS domain construction to these improved uniform
field boxes, then run the unchanged full 249-direction eigenpair proof on the
resulting independently paired domain. The input remainder is smaller only to
the extent justified by the new field enclosures. No midpoint domain radius is
chosen independently to obtain a passing test.

The two adapters load private module instances of the existing producers.
This preserves the original modules and their historical source bindings and
avoids changing the normalization producer's original-field dependency. Each
adapter binds its own source in addition to the complete underlying producer,
new theory and actual input artifacts. Their work directories and algorithm
identifiers are distinct from the original attempts.

A successful eigenpair proof must reproduce separately and still does not
establish the midpoint physical response, field, derivatives, remainder,
full-history coverage, physical quotient, Gate7 or observable predictions.
