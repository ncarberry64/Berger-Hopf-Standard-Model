# Current-center Green-directional endpoint curvature

The accepted replay supplies a nonzero signed Green image at every one of the
370 post-reset endpoints.  The current retained action is differentiated twice
along each resulting unit Green direction using 384-bit Arb, with the selected
center, branch, action coordinates, descriptor scale, and tangent frames held
fixed.

This extends the node-1 seed without reviving the old 48-seam calibrated-JAX
numbers or fitting a new anisotropic partition.  The reset node is deliberately
excluded: its Green image is exactly zero, so it has no normalized longitudinal
axis.

The result closes the endpoint operand only.  A longitudinal causal curvature
certificate still requires the correlated Hermite--Simpson midpoint direction,
the midpoint's second incidence generated by the endpoint rate variations, and
the frozen preconditioned causal composition.  Mixed Green/transverse curvature
and the transverse remainder remain separate downstream operands of the full
two-radius test.

The endpoint result is not uniformly small.  Its norm grows from an upper bound
of `0.027451526147420215` at node 1 to `139645314859.80203` at terminal node
370, a factor greater than five trillion, and the final 31 endpoint upper bounds
increase strictly.  This is certified raw local collapse-side stiffening, not
yet a causal obstruction: the Hermite--Simpson step incidence, midpoint term,
signs, and frozen preconditioner can only be adjudicated by composing them.
