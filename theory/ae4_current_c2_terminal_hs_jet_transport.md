# AE4 current-C2 terminal HS-jet transport

## Result

Let the action-owned downstream child or first physical domain exit supply a
finite terminal Weyl load and its two HS variations,

```text
L,                 u=D_H L,                 v=D_H^2 L.
```

The already-derived 1222-segment first-order product-Dirac factorization
transports these data exactly.  At fixed terminal value `L`, repeated
Möbius-chain differentiation gives

```text
D_H M_birth   = a + s u,
D_H^2 M_birth = b + 2 c u + q u^2 + s v.
```

Here `a,b` are the finite-core HS jets with the terminal jets held fixed,
while `s,c,q` are action-owned chain-rule transport coefficients of the
specified current-C2 core.  They are obtained by exact tangent propagation,
not by finite differencing a terminal boundary selector.

## Native negative-axis evaluation

The law was evaluated on the full current-C2 proof-center core at the existing
native probe `z=-1`, for both lowest product-Dirac chiralities and for two
reference terminal values: zero and the broad AE2 child-load upper enclosure.
For both reference values the coefficient `s` differs from one by less than
`1.2e-19` (and by much less at zero load).  Thus the finite core does not
suppress an unknown terminal first or second HS jet.  Setting those jets to
zero would be a physical assumption, not a consequence of the core
calculation.

This reduces the missing response at each fixed spectral parameter to two
explicit downstream data,

```text
D_H L_terminal(z),                 D_H^2 L_terminal(z),
```

rather than leaving an unspecified generic "tail correction."

## Claim boundary

The terminal HS-jet transport law is derived.  Neither reference terminal
value is selected as the physical maximal-history load, and the prior
covariant geometry-jet bounds are not relabeled as HS jets.  The action-owned
N12 maximal child—or the first physical domain exit—must still derive the
terminal load and these two HS variations before the maximal-history retarded
HS block or the integrated AE4 `E1` Hessian can be promoted.
