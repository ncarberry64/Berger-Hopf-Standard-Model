# Primal mean-value bounds on the paired affine endpoint tube

The same-family smoothness argument and exact geometry checks in
`n12_gate7_affine_basis_mean_value.md` also apply to the selected eigenvector
p and its bordered physical response (h,b). The all-75 Hessian diagnostic
already encloses their first variations in all scaled tube directions.
Integrating those first variations from verified point enclosures gives
uniform value enclosures. No new action evaluation or measured input is
introduced.

Use the first 61 rows of uniform solve 3 for Dp and all 62 rows of uniform
solve 4 for D(h,b). Apply the same longitudinal-plus-Euclidean support
formula, then add symmetric support balls to the verified point eigenvector
and point response. The point eigenvector must come from the certified
normalized eigenpair witness, not its floating proposal center. The point
response is complete verified point solve 0.

The last row of the projected eigenline solve is an auxiliary border
variable. Its right hand side already contains the separately computed
eigenvalue slope. It is not a bound on the eigenvalue derivative and must
not be integrated as one. This consumer does not tighten the eigenvalue.

Once independently paired, the resulting value boxes can replace wider
coordinates of the original value enclosures. They enclose the same true
family. The original inverse bounds remain valid on that family; they are
not asserted on arbitrary combinations in a newly inferred larger box.
The retained equations, branch, normalization, radii and data stay fixed.
Full physical input-basis and full-path closure remain separate obligations.
