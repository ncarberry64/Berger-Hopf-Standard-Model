# C2 adaptive-center majorant recentering

The 791-segment adaptive cover exhausts representable proof-radius shares at
the original reset-centered origin.  This is not invariant: the continuum
local theorem permits recentering at any regular state with retained margins.

Let `d` be the certified action distance from the original root to the last
adaptive proof center.  The retained global derivative bounds transfer the
center data by

`D3_new <= D3_old + D4_global d`,

`D rhs_new <= D rhs_old + D2 rhs_global d`,

and the corresponding selected-hard coupling, hard-rate Jacobi, `c_psi`, and
`b_psi` Lipschitz estimates.  The available parent radius is reduced by `d`,
and the complete recentered ball is checked inside both the original action
and selected-eigenline balls.

At the last adaptive center the transferred admissible radius remains
strictly larger than twice the incoming endpoint tube.  Therefore a nonempty
strict adaptive allocation interval exists with center-path coordinate reset
to zero.  This changes only the proof origin; the BHSM state, action, time
orientation, and endpoint rules are unchanged.
