# First-HS endpoint constraint tangent

At each of the 371 endpoints of the first contracted Hermite--Simpson center,
let `C_i` be the normalized 25-row action-constraint differential in the
98-dimensional weighted action coordinates.  This artifact materializes an
orthonormal basis `Q_i` of `ker(C_i)`, whose dimension is 73.

The basis orientation is immaterial.  Only the subspace and orthogonal
projector are used by the following intrinsic block solve.  This is a
binary64 numerical construction, not an outward interval enclosure and not
a continuous orbit certificate.
