# Universal benchmark suite

The benchmark evaluator turns a pre-comparison manifest into a cross-sector
release prerequisite.  Each requirement names an action-selected mode,
observable, allowed derived classification, required engines, and whether the
single universal scale map is required.

One frozen prediction must satisfy every row.  It must already be physically
promoted, use the suite's action version and physical background, use the
declared universal scale where dimensionful, and have every required engine
available.  Duplicate benchmark identifiers, duplicate mode/observable
pairs, provisional predictions, foreign scales, and missing engines fail
closed.

The manifest contains no measured value.  Experimental comparisons occur only
after the suite is complete and therefore cannot choose a branch, mode,
normalization, formula, or scale.  The present implementation supplies the
suite validator; no current BHSM benchmark prediction is promoted by it.
