# AE2 exact power-radius tail closure

Consider an exact infinite tail `R4=c(tau+tau0)^a`, `a>=0`. Every exponent now has a factorized E1 threshold route.

- `a=0`: the superpotential is asymptotically constant, so the continuum has threshold gap `beta^2`; any zero atom has exactly zero first form weight.
- `0<a<1`: on the region `x<=x_k=(beta/(2k))^(1/a)`, the positive-chirality barrier obeys `sqrt(V-k^2)>=sqrt(3)s/2`. Its Agmon action grows as `C k^(-(1-a)/a)`, so compact source weight is suppressed faster than every power. The negative chirality is the supersymmetric partner on nonzero spectrum.
- `a=1`: the exact Bessel source-Dini theorem applies, including its integrable critical logarithm.
- `a>1`: `integral d_tau/R4` is finite and the integrable-radius normalization theorem applies.

Thus every exact nonnegative power-law radius tail has a finite factorized E1 threshold integral. The actual N12 infinite-history asymptotic class remains unproved. The remaining mathematical class is a positive nonasymptotic/non-regularly-varying radius tail, unless the retained action supplies a controlled power asymptotic.
