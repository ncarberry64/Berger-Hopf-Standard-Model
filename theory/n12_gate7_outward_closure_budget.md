# Gate-7 signed outward closure budget

The exact center causal vector is used as a signed recenter, not discarded
by an early norm.  For an outward history write the propagator, directional
source, and mixed source as their center values plus perturbations.  The
strictly lower Volterra identity then bounds the error with four quantities:

1. relative causal-propagator defect;
2. relative directional-curvature drift;
3. relative mixed-curvature drift;
4. transverse-curvature inflation.

The propagator-defect term multiplying the already assembled signed center
source is included explicitly.  Thus the budget is sufficient for an actual
outward proof and is not the invalid assumption that the center Green map
remains fixed.

The generated JSON reports the independent limiting value of every
perturbation and the common balanced limit when all four vary together.
These are theorem-owned proof tolerances, not physical parameters or fitted
thresholds.  No outward value is promoted by this calculation.  Its purpose
is to make the remaining interval adapter minimal: certify the recentered
cone quantities against these tolerances without constructing a global
four-leg field tensor.
