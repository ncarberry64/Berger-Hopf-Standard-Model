# Cached endpoint defects of the current DOP853 center

Every native degree-seven coefficient is imported as an exact rational. The
alternating DOP853 dense basis is converted to power coefficients, evaluated
and differentiated exactly, and divided by the exact native action width.
The cached outward action rate is subtracted in Arb at 384 bits. Thus
`d = P' - F`, while the error equation receives the signed source `-d`.
The 98 state coordinates use the action weights; the final coordinate is the
same stored descriptor, without a clamp or an independently varied scalar.

At the native terminal fraction the rate packet evaluates the same polynomial
state divided by the exact weights. The producer checks that its cached raw
balls contain that exact point. The terminal defect is consequently an
outward signed point statement, including the cached action/eigenline rate
uncertainty. It does not establish a defect bound on any neighborhood.

The first cached rate evaluates the stored raw center. The native initial
action value instead contains the rounding of the original multiplication by
the weights. Their exact difference is saved. `P'(0)-F(raw_stored)` is a
reference defect, not an enclosure of `P'(0)-F(P(0)/W)`, until the rate
translation is bounded. No initial native field evaluation is invented.

The separate producer
`scripts/certify_n12_current_stop_native_initial_rate.py` now evaluates the
actual native initial point outward and saves its same-point signed defect
in `artifacts/current_runtime/current_stop_native_initial_rate/`. This
closes the initial rate-reference obligation by direct calculation; it
does not reinterpret or overwrite the earlier cached-reference packet.

For a continuous witness the missing operand is the correlated curve defect
on every current adaptive cell, with one common curve parameter for `P'`
and `F(P)`. Independent interval boxes discard the cancellation. The
physical constraints and descriptor graph need a normal chart and its
curvature, while a signed causal Green map must transport this source, the
certified fixed-descriptor initial inclusion, and the negative native seam
jumps. Point defects alone do not provide Green Y, Z1, or Z2.
