# Uniform ambient derivatives on paired physical HS boxes

The uniform-value pilot supplies independently reproduced rates on two
endpoint boxes and the actual Hermite-Simpson midpoint box generated using
uniform endpoint rates. This derivative pilot requires that entire paired
three-box result, including current source, runtime, domain, and eigenpair
bindings. Individual pointwise value or Hessian certificates cannot replace it.

For the selected endpoint or midpoint, reconstruct the recorded weighted box
outwardly and divide the state coordinates by the exact positive frozen
weights. This new reconstruction may enlarge the input domain. Consequently,
the derivative pilot constructs fresh interval action jets and proves a new
normalized eigenpair enclosure and index-24 inertia/orientation result on
that actual evaluation domain. It does not transfer the prior value pilot's
eigenpair proof to a larger domain. The original correlated affine trial set
remains the target; larger coordinate boxes supply conservative supersets.

The unchanged physical derivative kernel receives the complete exact 99 by
99 weighted augmented ambient identity. It returns the complete ambient DF
enclosure and a rate enclosure whose overlap with the paired uniform value is
checked. That overlap is a consistency check, not the uniform proof itself.
The interval-preserving Hessian graph then evaluates D2F[e_row,e_column] for
the explicitly selected columns, reusing the same newly verified interval
base. All 99 outputs are retained. State, descriptor, direction and arithmetic
uncertainty remain Arb balls at 512 bits throughout.

The default pilot evaluates the midpoint of interval 13, Hessian row 0 and
columns 0 and 98. These entries check the state and descriptor directions;
they are not a substitute for the full Hessian or its anisotropic contractions.
The complete uniform DF is also required later in the HS midpoint and second
chain rule. All three boxes can be evaluated separately by selecting the
endpoint/midpoint stage and index. Each invocation uses one numerical process.

Both input-domain arrays are saved before evaluation, so failed interval
solves, eigenpair inclusions or derivatives retain their actual attempted
domains and diagnostics. A separate repeat recomputes the full DF, selected
Hessian entries and eigenpair proof and must reproduce all scientific bytes.
Earlier receipts are archived before another attempt; mismatching candidates
are preserved. A coordinate-box failure is not evidence of singularity of
the smaller correlated affine domain.

Run `python scripts/certify_n12_gate7_uniform_physical_derivative_pilot.py
--interval 13 --stage midpoint --index 13 --preflight` after the paired uniform
value pilot exists. Preflight computes no action jets. Remove `--preflight`
for evaluation and repeat with `--recompute`. This is a uniform derivative
pilot on one selected box, not complete-history uniform coverage, a complete
Hessian, an HS remainder certificate, an intrinsic constraint chart, physical
quotient, contraction or continuum proof. Gate7 remains open.
