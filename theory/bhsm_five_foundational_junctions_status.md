# 1. Dimensionful scale bridge / \(r_{\rm prop}\)

## Canonical statement

A dimensionless Berger eigenvalue cannot by itself determine a number in GeV. If

\[
-\widehat\Delta Y_n=\lambda_nY_n
\]

and

\[
r_{\rm prop}=c_{\rm prop}\ell_\star,
\]

then in natural units

\[
\boxed{
m_n=\frac{\sqrt{\lambda_n}}{c_{\rm prop}}M_\star,
\qquad
M_\star=\ell_\star^{-1}.
}
\]

Thus BHSM has two distinct tasks:

1. derive the **dimensionless** localization quantity \(c_{\rm prop}\) from the action;
2. identify the provenance of the one common **dimensionful** scale \(M_\star\).

A separate fitted radius for each particle or sector would be nonpredictive. One universal
calibration scale, used once and then propagated through action-derived ratios, is a different
and much weaker assumption.

## Classical no-go

A classical action containing only dimensionless couplings, topological integers, and a global
scale modulus cannot generate a unique absolute metre/GeV unit from pure numbers alone.

For a homogeneous term,

\[
S(L)=CL^q,
\]

\[
\frac{dS}{dL}=qCL^{q-1}.
\]

For \(q\neq0\), no isolated nonzero stationary \(L\) exists unless the coefficient vanishes.
For \(q=0\), \(L\) is a flat modulus.

Different powers can stabilize a radius only if some coefficient or mechanism supplies the
required dimensional information (dimensionful action coefficient, boundary tension,
gravitational normalization, physical boundary condition, condensate normalization, quantum
transmutation scale plus renormalization condition, or one empirical dimensionful calibration).

## Current BHSM status

**LOCALIZED / ABSOLUTE UNIT OPEN.**

The current repository already distinguishes relative scale closure from absolute-unit
generation. It records an overall scale degeneracy and does not promote an absolute unit from
dimensionless topology alone. Historical scale work conditionally fixes relative quantities,
while later physical-map work permits one explicitly declared common calibration.

The remaining particle-physics issue is stronger than the old generic radius objection:
the current physical history still requires an **action-selected state-dependent localization
scale / physical relative-energy or pole functional** before physical masses are derived.

## Closure criterion

Objection 1 is physically closed only when the repository supplies:

\[
\partial_AU(q_\star)=0,
\qquad
H_{\rm phys}(q_\star)>0
\]

for the localization/modulus variables \(q^A\), and then uses one universal \(M_\star\) source
without sector-by-sector retuning.

# 2. Action-coupling dimensional consistency

## Correction to the original objection

BHSM does **not** need to dynamically derive \(\hbar\) and \(c\) from its metric. They may be
restored as unit-conversion constants. The real field-theory question is whether every physical
operator carries the required action normalization.

In four-dimensional natural units,

\[
[x]=-1,\qquad [\partial]=1,\qquad [R]=2,\qquad [\mathcal L]=4.
\]

Therefore a linear curvature term requires

\[
\mathcal L\supset M_\star^2R.
\]

A curvature-squared term can instead carry a dimensionless coefficient:

\[
\mathcal L\supset \alpha R^2.
\]

A boundary tension carries its own nonzero mass dimension.

Newton's constant \(G\) is required specifically if the curvature coefficient is identified
with Einstein gravity,

\[
M_{\rm Pl}^2\sim G^{-1},
\]

not merely because an internal Berger curvature appears.

## Canonical obstruction

\[
\boxed{
\text{dimensionless internal curvature cannot be identified directly with physical energy
density without an action normalization of the appropriate mass dimension.}
}
\]

## Current BHSM status

**CORRECTED / LOCALIZED / OPEN where physical normalization is absent.**

The repository already treats the absolute scale and several current residues/normalizations
as open. Future audits should test the dimensions and provenance of the action coefficients,
not demand that pure geometry manufacture \(\hbar\), \(c\), and \(G\).

## Closure criterion

Every physical action term must have the correct dimension and every dimensionful coefficient
must have explicit provenance. A single common calibration may be retained if the claim is
finite-input physical completion rather than parameter-free absolute-unit generation.

# 3. Proxy functionals versus true variational eigenmodes

## Canonical distinction

A harmonic formula such as

\[
m_{\rm proxy}=F(\lambda,k,j,\ldots)
\]

can demonstrate kinematic admissibility or organize a spectrum. It becomes a physical mass
formula only if it arises from the quadratic fluctuation operator of the same nonlinear action
that defines the physical background and boundary/domain.

Let

\[
\Phi=\Phi_\star+\sum_na_nY_n.
\]

The action must reduce to

\[
S^{(2)}
=
\frac12\int d^4x\,
\left(
K_{mn}\partial_\mu a_m\partial^\mu a_n
-
M^2_{mn}a_ma_n
\right),
\]

with physical masses obtained from

\[
\det(M^2-m^2K)=0
\]

or the corresponding Lorentzian pole/Floquet problem.

The background must itself satisfy the complete Euler--Lagrange equations and the constrained
physical Hessian must be nonnegative, with positive directions for genuine massive modes.

## Current BHSM status

**LOCALIZED / PHYSICAL MASS OPEN.**

The current repository has progressed beyond a purely algebraic proxy:

- a current-domain product-Dirac quadratic piece is attached;
- first/second/contact source jets are derived on that domain;
- a first-order charged-lepton LR operator is assembled;
- finite-core advanced/retarded Green existence is derived;
- harmonic shortcuts have been screened rather than promoted.

But the repository still does **not** derive the current physical charged-lepton poles or
family mass hierarchy. The current action also lacks, on the same final domain, all ingredients
needed for a normalized manifestation/energy or pole functional and an action-selected
localization scale.

## Closure criterion

A mass/mode claim becomes physical only when the same action supplies:

1. stationary physical background;
2. self-adjoint/hyperbolic physical domain;
3. canonical kinetic normalization or pole residue;
4. quadratic mass/pole operator;
5. positive constrained Hessian / stable physical branch;
6. no empirical retuning of the eigenvalues or localization scale.

Historical harmonic formulas should remain labelled `PROXY`, `SCREEN`, or `CONDITIONAL`
until this chain is complete.

# 4. Chiral fermions and the Dirac/index problem

## Correction to the original objection

The statement

> "compact Berger \(S^3\) automatically gives a vector-like spectrum with one right-handed
> mirror for every left-handed mode"

is too broad.

An odd-dimensional Berger sphere can have a spectrally asymmetric Dirac operator. More
importantly, ordinary four-dimensional Weyl chirality is not obtained simply by counting
positive and negative eigenvalues of an isolated 3D Dirac operator.

The correct BHSM question is whether the **full action-owned boundary/seam/bulk Dirac problem**
with its declared self-adjoint boundary conditions produces the required net chiral
four-dimensional content.

The natural topological diagnostic, where applicable, is an APS/domain-wall type index:

\[
\operatorname{ind}D
=
\int_W\widehat A(R)\,\mathrm{ch}(F)
-
\frac{\eta(D_{\partial W})+h}{2}.
\]

The actual formula must match the dimension, bundle, gauge representation, and boundary
conditions used by BHSM.

## Current BHSM status

**CORRECTED / LOCALIZED / CHIRAL DERIVATION OPEN.**

The repository already contains current-domain chiral Dirac pencils/operators and preserves
left-handed weak-current structure in the effective local action. It also explicitly records
that:

- the boundary Dirac domain/index is still open;
- orientation/projector conjugation does not by itself prove a chiral index;
- a BHSM-native physical derivation of the complete chiral spectrum remains unfinished.

Therefore BHSM should not be described as having *no* chiral machinery, but it also should not
claim that Standard Model chirality has been derived from geometry.

## Closure criterion

The chiral problem is closed only when one action/domain calculation establishes all of:

1. the physical Dirac operator;
2. its self-adjoint / causal boundary domain;
3. the relevant index or spectral-flow statement;
4. the correct net left-minus-right representation multiplicities;
5. absence or decoupling of unwanted mirror states;
6. gauge and mixed anomaly cancellation on the same representation content.

# 5. Scattering matrix, widths, cross sections, and unitarity

## Correction to the original objection

Differential geometry does not have to "directly output probabilities." The normal route is

\[
\text{geometric action}
\rightarrow
\text{linearized fields}
\rightarrow
\text{quantization/state}
\rightarrow
\text{propagators and vertices}
\rightarrow
\text{correlators}
\rightarrow
\mathcal S .
\]

The relevant obstruction is therefore not geometry itself. It is whether BHSM has completed
the quantum/asymptotic structures required to define physical amplitudes.

## Current BHSM status

**LOCALIZED / S-MATRIX OPEN.**

The repository already contains pieces that are prerequisites for scattering:

- finite-core advanced/retarded Green existence for the assembled fermion operator;
- a nonempty quasifree Hadamard state class on certified globally hyperbolic members;
- state-dependent time-ordered Feynman two-point distributions;
- current-domain source vertices and quadratic operator blocks.

But it explicitly does **not** yet have:

- a uniquely selected physical state/asymptotic state class;
- normalized physical pole residues for the full particle content;
- a normalized photon propagator on the current domain;
- all physical interaction vertices on one compatible action/background/domain;
- a transition-probability law or demonstrated unitary scattering operator.

Thus "BHSM has no S-matrix" remains true as a final physical statement, but "BHSM lacks all
operator machinery needed to begin one" is no longer accurate.

## Minimal closure route

For a stable/asymptotically controlled physical background:

1. choose or derive the physical in/out or Hadamard state;
2. canonically normalize the quadratic action;
3. locate physical poles and residues;
4. derive cubic/quartic vertices from the same action;
5. construct amputated connected correlators;
6. apply LSZ where an asymptotic particle interpretation exists, or the appropriate curved-
   spacetime/algebraic scattering construction otherwise;
7. verify optical-theorem / Ward / BRST identities and positivity.

The first nontrivial BHSM collider-style calculation should be a minimal allowed
\(1\to2\) decay or \(2\to2\) channel, not a full LHC event simulation.
