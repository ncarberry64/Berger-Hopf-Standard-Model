# Theory and derivation record

This directory preserves derivations, conditional results, scoped no-go results,
candidate constructions and their historical successors. File age and version
number alone do not determine which result governs a present calculation.

Start with the [repository guide](../docs/REPOSITORY_GUIDE.md),
[gate ledger](gate_ledger.md), [claim boundaries](../CLAIMS.md) and
[open research register](../docs/OPEN_RESEARCH.md).

For a scientific statement, identify its action, domain, state, normalization,
inputs and source revision. Follow explicit successor links and compare the same
operands before transferring a theorem or a failure to another construction.
Retain distinctions between algebraic identities, conditional theorems,
finite numerical tests, historical screens and physical predictions.

Keep the original derivation and its citations when adding a successor. Link
reviewed numerical evidence to its generator and tests in the
[artifact catalog](../ARTIFACT_INDEX.md). The
[documentation index](../docs/README.md) preserves the campaign reading paths.
