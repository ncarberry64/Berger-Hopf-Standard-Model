# Gate-7 compute-justification audit

The immediate proof-support obligation is to localize the current mixed
Green/transverse map over every post-reset endpoint with a defined Green
axis.  This reconnaissance does not itself promote an outward theorem.  It
selects the smallest credible extremal proof set for the subsequent direct
bilinear versus polarization enclosure.

Nodes 1 through 80 already exist as 512-bit restart-safe shards and are
attested by content hash.  They must not be recomputed.  Node 0 is excluded
because its Green image is zero and a normalized Green axis does not exist.
The first adaptive screen at 128-bit Arb precision was finite but insufficient:
its maximum scaled component radius was approximately `0.3963`.  The next
screen at 192 bits reduced the corresponding maximum below `1.05e-16`, so 192
bits is the minimum admitted continuation precision.  Independently certified
512-bit seeds remain the authority at decisive proof nodes.  Precision is to
be escalated only at nodes selected for an outward proof.

There is no certified symmetry, monotonicity, convexity, or interval
interpolation theorem that currently removes an unknown endpoint extremum.
Within each node, bilinearity already replaces 148 polarized directional
evaluations with one shared-generator matrix traversal.  Completing this
adaptive direct survey is therefore the cheapest presently justified way to
retire exhaustive polarization without assuming the location of an extremum.

After the survey, no further global campaign is authorized automatically.
The next unit must derive the outward algebraic equivalence on a small
certification set and use an analytic remainder to cover omitted nodes or be
packaged as an external HPC proof job.

One-, two-, four-, eight-, and sixteen-worker measurements were made only on
useful, nonduplicate campaign nodes.  Eight workers are the cost-effective
throughput knee: they provide substantially more throughput than four, while
sixteen workers increase CPU-hours per node by more than thirty percent due
to contention.  The continuation therefore uses eight workers.
