# N12 core-transmitted physical-manifold audit

The owner hypothesis that only a manifold transmitted from the BHSM core is
physically populated is scientifically admissible as an ontology hypothesis,
but it is not presently a theorem of BHSM-AE-2.0.0.

The repository contains one object with exactly the requested formal type,
`T_core:(core phase data)->(boundary phase data)`, but its transfer operator,
domain, matching laws, and rank are all explicitly null.  The later retained
action analysis explains the obstruction.  The regular Haar core endpoint is
Weyl limit-point; every smooth nondegenerate codimension-one trace has positive
capacity, so the compactified `upsilon=0` trace costs infinite regular action.
The accompanying `I_W=0` condition is reconstruction rank loss, not a regular
boundary state or a transmission channel.

BHSM-AE-2.0.0 does not cure that core obstruction.  Its unitary `U_R` is a
coefficient-free map between the last regular event trace and the first regular
child trace.  It has graph rank four in the stored finite witness, but the
action version states explicitly that no continuous pregeometric core spinor
trace or flux is added.  Thus `U_R` is a valid event-child seam map and an
invalid occupant of the pregeometric core-to-boundary slot.

The 139/73/67/66 dimensions retain their current meanings:

- 139 is the tangent dimension of the full moving event-child correspondence;
- 73 is the rank of its projection to the child state;
- 67 is the child constraint fiber after fixing the event;
- 66 is the retained physical child-history count after the one-dimensional
  whole-history time quotient.

No audited core object supplies an additional action-derived projector on any
of these spaces.  Consequently none of those dimensions may be reduced under
the core-transmission hypothesis.  The fixed-`s` vector-field tangency question
is not false; it is undefined until a nonempty regular transmitted manifold is
actually supplied.

The proposed value `a=1/118` is recorded only as an owner-authorized candidate.
No current repository formula or artifact derives or even identifies that
number as the rank projector or strength of a core-transmission map.  It is
also distinct from the historical `alpha_3=7/(6*pi^2)=0.118208...`, which is a
downstream matching screen, not `1/118`.  The measured or candidate value is
not inserted into the action, reset chart, KKT equations, or frozen prediction
