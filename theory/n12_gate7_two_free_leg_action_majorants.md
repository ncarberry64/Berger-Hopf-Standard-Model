single output leg used by the earlier directional certificate.  The retained
MixedBound calculation therefore receives

`[I_98, I_98, c_hat, c_hat, c_hat]`.

Its mixed slots `d[3]`, `d[7]`, `d[15]`, and `d[31]` enclose respectively
`D2L`, `D3L[c_hat]`, `D4L[c_hat,c_hat]`, and
`D5L[c_hat,c_hat,c_hat]` as two-free-leg action operator norms.  The action
ball is applied before the tensor norm, so the `D4` value is already outward
on the uniform `3.6e-6` action ball.

normalized SHA-256 equals the expected committed hash; otherwise it evaluates
that committed Git blob in memory.  This certificate does not yet perform the
