# AE3.1 current-C2 `r2` electron-capture selection rule

Recall separates three objects that had been compressed into the name `r2`.
The v14.83 theorem derives an `ell=2` negative-semidefinite shear correction
to a reduced stiffness.  The equal-inertia coefficient `chi2=2/(3R^2)` is
conditional, and v14.85 evaluates the physical relative transport and the
shear operator to zero on the retained stationary classical branch.  This is
not an electron orbital.

An `ell=2` metric response can nevertheless enter the covariant electron
action without a new coefficient. If an action-owned intertwiner produces
`h_mu_nu=r2 h_mu_nu^(2)`, then

```text
delta_h S_e = (1/2) integral sqrt(-g) h_mu_nu T_e^(mu nu)
```

defines the mixed electron/geometry Hessian.  That full-preimage-to-physical-
`M4` intertwiner has not yet been derived, so the numerical block cannot be
inserted.

There is also an exact round-background selection rule. On unit `S3`, choose

```text
Y0=1/sqrt(2 pi^2),
Y2=(sqrt(3)/pi)(x1^2-x2^2).
```

Then

```text
integral Y0*Y2*Y0 = 0,
integral Y2*Y2*Y0 = 1/sqrt(2 pi^2) != 0.
```

Thus a trace-free `ell=2` response gives no common first-order diagonal
binding shift in the isotropic trace of the round lowest multiplet. It can
mix the lowest channel with an `ell=2` component, and the unevaluated full
spinor block could also split internal degeneracy. The scientifically
admissible statement is that `r2` may dress a capture state; it is not itself
the capture orbital and does not generate an isotropic stationary lowest mode
alone.

The current charged weak representation already contains both

```text
bar(nu_eL) gamma^mu e_L,
sum_color bar(u_L) gamma^mu d_L.
```

But a physical capture Hessian still requires the returned proton and neutron
composite states, their hadronic weak-current matrix element, the complete
electron environmental operator, and the outgoing neutrino boundary trace.
None is replaced by a measured capture rate or neutrino splitting.
