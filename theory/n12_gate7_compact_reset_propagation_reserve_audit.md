`delta_i <= G_i (1 + ||D eta||) rho`.

For each retained chart, define its output reserve as the certified local radius minus the already consumed pointwise center/tube radius.  The exact field names depend on the existing block: translated/adaptive charts use their local ball radius minus endpoint tube; cancelled-fiber and uniform-gap charts use selected-ball radius minus root use; Lohner charts use selected-domain radius minus joint-domain use.  This is an audit of stored certificates, not a replacement continuation.
