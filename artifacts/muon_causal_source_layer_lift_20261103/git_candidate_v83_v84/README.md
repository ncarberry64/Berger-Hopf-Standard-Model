# Review candidate: forced event component and causal source lift

This small research package contains v83/v84 derivations, exact arithmetic
verifiers and deterministic evidence. It is prepared locally for a future
Git milestone. Nothing in this package has been uploaded or staged.

The established results are a forced two-face native product map, its source
range limitation, a conditional incoming-to-layer lift with independent left
data, and an energy-form bound for complete matched loads. One ordered
source term survives the simple factor-kernel cancellation test. The full
physical background, event graph and native-relative source completion are
still required. No physical reconnection, a_mu, g_mu or total uncertainty
is computed. The physical 2e-10 guard is unchanged.

The v83 verifier has 22 exact checks and was reused from its verified
checkpoint. The v84 verifier has 28 exact checks and two byte-identical final
replays. These check algebra and kernels, not a physical numerical residual.
No archived owner code is imported by the verifiers. Owner excerpts document
provenance and their explicit limitations.

Reproduce with C:\Python314\python.exe -I -S, the relevant verifier path,
and --out pointing to a fresh child directory of that verifier's folder.
The source explicitly refuses a different or unbounded startup environment.
For another machine, review and bound its interpreter before a documented
port; do not remove this check silently. No third-party package is needed.

INVENTORY.json hashes every candidate payload except itself; its own hash
is recorded in the enclosing local publication inventory. REVIEW.json
records the bounded content review and exclusions. Publication audits and
approval remain required before a later release. This is not a clean-bill
security assessment of the machine or permission to publish.
