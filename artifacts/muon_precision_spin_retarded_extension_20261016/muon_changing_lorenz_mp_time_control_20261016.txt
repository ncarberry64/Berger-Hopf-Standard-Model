1. COMPLETED TIME6 IS REUSED WITH AN EXPLICIT ROUNDING ENVELOPE

Let a be an already computed MP80 time6 entry and c its stored nearest
float64 conversion. Define the conservative MP-valued radius
 r=one half*max(c-nextafter(c,-infinity),nextafter(c,+infinity)-c).
The code lifts both neighboring floats exactly and performs the differences
and halving in MP. It checks finiteness of c and BOTH neighbors. This
handles powers-of-two binades, zero, positive/negative subnormals without
pretending Windows longdouble has higher precision. Explicit controls at
0,+/-smallest subnormal,+/-1 are retained.

For a new unrounded MP8 value b, |a-c|<=r implies
 |b-a|<=|b-c|+r,
 max(1,|a|,|b|)>=max(1,|c|-r,|b|).
The reported every-entry ratio upper bound is therefore
 (|b-c|+r)/max(1,|c|-r,|b|).
The maximum is scanned over every full B,F and fixing matrix entry, with
absolute bound, worst index and values recorded. This reuses the completed
MP80 arithmetic reference; it is not a claim that the underlying physical
operator or upstream coefficients are interval certified. It avoids
recomputing settled time6 fields just to recover sub-ulp output digits.
