## Reproduction

Use Python with python-flint at 512-bit precision. All producers refuse to
overwrite outputs. Supply the retained evidence checkout with
`--evidence-root`; its exact NPZ/header hashes are recorded in each result.
Output paths do not change the mathematics; recorded absolute paths identify
the original local evidence and source bindings.

1. Run `certify_n12_gate7_cubic_tube_rows.py` with `--interval 13 --cells 8`
   and each selected pair `0 1`, `2 3`, `4 5`, `6 7`; run each twice in fresh
   processes. Run `certify_n12_gate7_augmented_tube_domain.py` twice.
2. Validate and package with `package_n12_gate7_physical_tube_atlas.py`.
   Its work filenames follow the `interval13_cubic8_cells0_1_first.json`
   pattern in this directory, with `_repeat` for the independent run.
3. Run `derive_n12_gate7_local_ball_rate_jet.py` for each `--site left`,
   `middle`, `right`, binding the matching cell-pair and augmented records.
   These broad coordinate enclosures are retained as an explicit failed
   screen and as the initial incidence input to the refined producer.
4. Run `derive_n12_gate7_inherited_site_rate_jet.py` for each site, twice,
   with its original broad result as `--direction-file`. This producer
   reconstructs and contracts the complete incidence maps before support,
   imports original primal/first jets, and evaluates the new mixed graph.
5. Place the refined paired outputs in a fresh assembly directory under the
   names `interval13_ballrate_{site}_{first|repeat}.json`; this is a byte copy,
   not a numerical transformation. Run
   `assemble_n12_gate7_local_tube_remainder.py` twice using that directory.
6. `package_n12_gate7_physical_tube_checkpoint.py` verifies the pairs,
   consumed source hashes, atlas authority and explicit nonviability.

The next refinement must keep shared signed state/direction coefficients
and mixed monomials through the implicit solves, descriptor normalization,
booked subtraction and causal output contractions. No larger history claim
