Manual RC5 submission preparation

From the paper directory run `python submission/rc5/prepare_submission.py /path/to/new/manual-files`. The script checks the 198-word plain-text abstract, formal BHSM product pin and visually reviewed45-page PDF, then verifies every focused-source ZIP member. It uploads nothing and asserts no final author approval, journal agreement or payment. Historical RC4 and preliminary RC5 draft records remain separate. Hosted CI and the complete reviewer packet are bound separately in final release receipts.
