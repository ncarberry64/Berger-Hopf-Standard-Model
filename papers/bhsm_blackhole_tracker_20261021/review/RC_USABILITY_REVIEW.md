## Remaining limitations and minor polish

- **P3, optional error-copy polish:** a ragged covariance is correctly rejected, but its error appends NumPy's inhomogeneous-shape wording after the useful `covariance must be a rectangular numeric array` phrase. A short expected-row/column explanation would be easier for a first-time scientist. This does not silently accept, reshape or replace the input.
- The GUI accepts native JSON. CSV users are explicitly directed to the complete downloaded bundle and its installed CLI conversion command; a graphical three-file CSV importer is not claimed.
- The installation review used a clean wheel environment sharing already available scientific dependencies. It did not simulate a machine without Python/network access, test another operating system, or independently certify a fresh package-index installation. Root owns launcher/path/port-conflict checks and final browser evidence.
- The reviewed examples are synthetic. The stellar example adapts published parameter choices; this execution did not run the BAGLE engine or turn that example into observational data. Provenance remains a declaration, not authentication.
- Supplied distances, angular frame, time convention, image association, parallax factors and flux/delay calibrations remain physical prerequisites. Their uncertainty is not inferred. Visible local covariance/profile outputs do not resolve equivalent-potential, source or calibration degeneracies beyond the adopted model.
- No cancellation, cross-session persistence, general caustic/image enumeration, cosmological/horizon closure, microscopic BHSM selection or exclusive-theory identification is implied by a completed compact-source fit. The interface states the relevant current limits and does not require a departure from ordinary gravity for its BHSM interpretation.

Current README first-run, units/order, parity, installation, replay and profile instructions were read against the installed commands. The previously stale statement about profile parent directories is corrected in current source. No unresolved documentation blocker was identified in those paths.
